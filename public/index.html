Exportar dados

Deixe as datas em branco para exportar tudo. O arquivo é salvo pelo seu navegador (pasta de Downloads).

Importar planilha (.xlsx)

Aceita o layout de backup do Zenply (colunas: Tipo de Lançamento, Data Pagamento, Data Competência, Descrição, Valor, Categoria, Recebido de/Pago a, Pago, Detalhes, Conta, Centro de Custo, Tags). A coluna "Conta" deve ser o nome de um perfil já existente (ex: "Pessoal"). Contas bancárias e perfis nunca são criados/alterados pela importação — só categorias, contatos, centros de custo e tags novos.

Excluir todos os dados

Isso apaga permanentemente todos os dados salvos em data/db.json nesta máquina (contas, lançamentos, categorias, contatos etc.) e recria o app do zero.
